# FetchUserDetailReact

This is a React application that fetches and displays user details.

## Installation
1. Make sure you have Node.js installed on your computer.
2. Create one folder and open cmd or gitbash.
3. Clone the repository using below command:
    1. git clone https://github.com/JayeshNeosoftTech/FetchUserDetailReact.git
4. Navigate into the project directory:
    1. cd FetchUserDetailReact
    2. npm install (to install node modules)
    3. npm start
